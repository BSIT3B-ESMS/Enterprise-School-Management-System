# ADMITONE Applicant Portal

Responsive applicant-facing frontend for the ADMITONE online admission system. It includes an application overview, personal information form, document selection, entrance exam sessions, notifications, and profile settings.

## Run locally

Open `index.html` in a browser, or serve the project folder with a local web server. Bootstrap, jQuery, and the selected fonts are loaded from CDNs, so an internet connection is needed for those assets.

## Prototype scope

This is a frontend prototype. Form saves, document selection, exam session selection, notifications, and profile changes are client-side demonstrations only; authentication, API persistence, document transfer and verification, and admission decisions require a connected backend.
