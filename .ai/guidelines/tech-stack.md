# Tech Stack

This is a server-rendered Laravel application — no SPA. The frontend baseline is Bootstrap (Sass + JS) with jQuery and jQuery UI, compiled exclusively through Vite. There is no Tailwind (it was removed).

## Installed stack

Versions drift. Before relying on a package's API, confirm the installed version:
- PHP packages: `composer show --direct`, or `composer show <vendor/package>`.
- JS packages: look in `package.json`.

## Where to look each library up

- **Laravel** (incl. Blade views/components, Vite integration): use Boost's `search-docs`.
- **Bootstrap**: Context7 `/websites/getbootstrap_5_3` (covers getbootstrap.com/docs/5.3) — Sass customization, components, `data-bs-*` JS behavior.
- **jQuery**: Context7 `/websites/api_jquery` (api.jquery.com), plus the jQuery 4.0 upgrade guide — jquery.com/upgrade-guide/4.0 — for removed APIs.
- **jQuery UI**: jqueryui.com/demos and api.jqueryui.com (the project is in maintenance mode). There is **no Context7 source** for jQuery UI — use web search or read the installed package source.
- **Vite**: `vite.config.js` and the official vite docs.

## Meta rules

- `AGENTS.md` is generated by Laravel Boost (`php artisan boost:update`, also run automatically after `composer update`). **Never hand-edit content inside the `<laravel-boost-guidelines>` block** — it will be overwritten.
- Durable project documentation lives in:
  - `.ai/guidelines/` — always loaded by every agent (this file is auto-inlined as the `tech-stack` section).
  - `.ai/rules/` — path-scoped rules, loaded via `.ai/rules/index.md` before editing matching files.
- Never add assets via CDN `<script>`/`<link>` tags. All frontend assets are bundled by Vite and loaded through `@vite`.
- Do not change dependencies without approval.
- Key commands: `npm run dev`, `npm run build`, `composer run dev`, `php artisan test --compact`, `vendor/bin/pint --dirty --format agent`.
- If a frontend change doesn't appear in the UI or you hit "Unable to locate file in Vite manifest", rebuild with `npm run build` (or ask the user to run `npm run dev`).
